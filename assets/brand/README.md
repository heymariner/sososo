# HeyMariner brand assets

## Logo

- `heymariner-logo.svg` — a clean SVG recreation of the HeyMariner logo:
  a stylised mermaid silhouette in navy (`#0B2C4A`) with a teal wave tail
  (`#14919B`), and the wordmark "HeyMariner" in navy. It is used in
  generated image cards until the original logo file is available in the
  repo. Only the two brand colours are used.
- `heymariner-logo.jpg` — **not in the repo yet.** The original logo JPG
  uploaded by the user should be placed here manually at
  `assets/brand/heymariner-logo.jpg`. GitHub push tooling does not support
  binary uploads, so this file cannot be added by the automation that built
  this repo — add it by hand (web upload or `git add` locally) when ready.
  Once it is present, generated cards should prefer the JPG; the SVG stays
  as a clean, scalable fallback.
